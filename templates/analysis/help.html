{% translate "2. 単一バリアント解析" %}

{% translate "1 つのバリアントを ACMG 2015 + ClinGen SVI 基準で分類します。" %}

{% translate "入力形式" %}

{% translate "次のいずれの形式でも入力できます（MANE Select / MANE Plus Clinical の transcript に限定して解釈します）。" %}

  • {% translate "genome 座標" %}: chr17:7674221G>A
  • {% translate "cDNA" %}: TP53:c.742C>T {% translate "または空白区切りで" %} TP53 742C>T
  • {% translate "protein" %}: TP53:p.R248W {% translate "または空白区切りで" %} TP53 R248W

{% translate "アセンブリ (GRCh38 / GRCh37) を選び、必要なら入力種別を指定します（通常は自動判定で問題ありません）。" %}

{% translate "in silico 予測ツールの選択（PP3/BP4）" %}

{% translate "ミスセンス変異の PP3/BP4 に使う予測ツールを選べます。学習データを共有するツールを足し合わせるとエビデンスを過大評価するため、使用するのは常に 1 つだけです。選んだツールは体細胞評価の OP1/SBP1 にも使われ、結果画面と「使用データの版情報」に表示されます。" %}

  • ESM1b{% translate "（既定）: Brandes et al., Nat Genet 2023。PP3 は LLR ≤ −24.0 / −14.0 / −12.2 / −10.7 で Strong / +3 / Moderate / Supporting、BP4 は LLR ≥ 8.8 / −3.2 / −6.3 で +3 / Moderate / Supporting（Bergquist et al. 2024 の較正）。MIT ライセンスで商用利用も可能です。" %}
  • FuncVEP-CTI{% translate ": Kayaalp et al., Nat Genet 2026。全ミスセンス変異の計算済みスコアを使い、論文の補足表の点数別閾値で PP3 は CTI ≥ 0.9109 / 0.8583 / 0.8023 / 0.6903 で Strong / +3 / Moderate / Supporting、BP4 は CTI ≤ 0.0174 / 0.0262 / 0.0643 / 0.1352 で Strong / +3 / Moderate / Supporting を与えます（ESM1b と違い BP4 でも Strong に達します）。スコアは PolyForm Strict License 1.0.0 で非商用利用限定・再配布不可のため、既定には設定しておらず、選択したときだけ参照します。" %}

{% translate "スコアが登録されていない変異（ミスセンス以外や未収載）では、そのツールでは PP3/BP4 は付きません。ツールごとに結果は別々にキャッシュされます。" %}

{% translate "候補の選択" %}

{% translate "変換結果が複数候補ある場合は一覧から該当するバリアントを選択します。c./p. の番号が MANE Select と MANE Plus Clinical で別の座標を指す場合は両方を提示します。MANE で座標が得られない場合は、全 transcript 候補にフォールバックして提示します。Plus Clinical の候補（「Plus Clinical で解析」）を選ぶとその transcript で評価した結果を表示し、結果画面の「評価する transcript」で MANE Select と切り替えられます。VCEP の位置規則と ClinVar の同一コドン照合は、どちらの評価でも MANE Select の番号で照合します。" %}

{% translate "結果の見方" %}

  • {% translate "ACMG 2015 と Bayesian の 2 方式の分類、および Bayesian スコアを表示します。" %}
  • {% translate "各クライテリアの判定 (MET / not met / suppressed)・方向・strength・points・根拠を一覧で確認できます。" %}

{% translate "手動編集と再分類" %}

  • {% translate "クライテリアごとに「編集 strength」を選び、根拠を入力して「編集を適用して再分類」を押すと、その場で再計算します。" %}
  • {% translate "「（変更なし）」のままの項目は自動判定を保持します。" %}
  • {% translate "手動編集による再分類の結果はデータベースに保存されません" %}{% translate "（元の自動解析結果は保存されます）。" %}

{% translate "結果のダウンロード" %}

  • {% translate "「JSON でダウンロード」「TSV でダウンロード」から保存できます。" %}
  • {% translate "手動編集を行った場合は、画面に表示されている（編集後の）内容がそのままダウンロードされます。" %}

{% translate "体細胞変異としての評価" %}

  • {% translate "結果画面上部の「Germline」「Somatic」タブで表示を切り替えます。Somatic タブには、腫瘍で検出された変異としての Oncogenicity（ClinGen/CGC/VICC SOP、Horak et al. 2022 の点数制）と AMP/ASCO/CAP 2017 の tier（Li et al.）を表示します。" %}
  • {% translate "tier には腫瘍型（OncoTree コード、例: SKCM、COADREAD、NSCLC）が必要です。空欄のときは tier を付けず、他の腫瘍型での根拠を参考として表示します。" %}
  • {% translate "tier の根拠は CIViC（CC0）と ClinVar の Somatic Clinical Impact です。OncoKB・COSMIC など利用許諾が必要なデータは使用していません。" %}
  • {% translate "OP2 など自動で判定しないクライテリアは、「適用」「不適用」で手動の根拠として与えて再評価できます（保存はしません）。" %}
  • {% translate "JSON / TSV のダウンロードは、どちらのタブからでも生殖細胞系列と体細胞の両方の結果を含みます（体細胞の情報が不足するときに生殖細胞系列の情報を参照できるようにするため）。TSV のクライテリア表は framework 列（ACMG / somatic）で区別します。" %}

{% translate "3. バッチ解析 (VCF)" %}

  • {% translate "VCF ファイル (.vcf / .vcf.gz、上限 50MB) をアップロードし、アセンブリを選んで投入します。" %}
  • {% translate "解析は投入順に直列処理されます。ジョブ状態画面で進捗を確認でき、完了すると結果 TSV をダウンロードできます。" %}
  • {% translate "評価モードで「生殖細胞系列＋体細胞の統合」を選ぶと、生殖細胞系列の列に加えて各変異の Oncogenicity と（腫瘍型を指定したとき）AMP/ASCO/CAP tier を同じ TSV に出力します。" %}
  • {% translate "過去のジョブは「ジョブ履歴」から確認できます。" %}
  • {% translate "アップロードファイルと結果ファイルは保持期間 (既定 1 時間) を過ぎると自動削除されます。必要な結果は早めにダウンロードしてください。" %}
